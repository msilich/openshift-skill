# Removed features

The following release notes detail the removed features for the Red Hat OpenShift Dev Spaces 3.29 general availability release.

Removed features are those that were deprecated in earlier releases. They are now removed from Red Hat OpenShift Dev Spaces 3.29, and will no longer be supported.

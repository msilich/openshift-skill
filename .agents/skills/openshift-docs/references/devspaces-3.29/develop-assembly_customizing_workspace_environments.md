# Standardize workspace environments

Standardize workspace environments by configuring workspace components using devfiles so you can give every developer the same tools and runtimes.

- **[Devfile in OpenShift Dev Spaces](develop-con_devfile_introduction.md)**  
  Devfiles are `yaml` files used for development environment customization. Share devfiles across workspaces to ensure consistent build, run, and deploy behavior across your team.
- **[What you can customize in a Cloud Development Environment](develop-con_customizing_workspace_components.md)**  
  OpenShift Dev Spaces provides several options to customize your workspaces to match project requirements and team standards.

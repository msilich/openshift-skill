# Deprecated features

Deprecated features are still included in Red Hat OpenShift Dev Spaces 3.29 and continue to be supported during this version’s support cycle. However, the feature will be removed in a future release of Red Hat OpenShift Dev Spaces and is not recommended for new deployments.

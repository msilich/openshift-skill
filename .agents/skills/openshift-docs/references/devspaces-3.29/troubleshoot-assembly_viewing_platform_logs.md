# View Cloud Development Environment logs

View OpenShift Dev Spaces Cloud Development Environment logs to diagnose startup failures, debug server and operator issues, and identify infrastructure problems.

- **[Cloud Development Environment logs](troubleshoot-ref_viewing_devspaces_workspaces_logs.md)**  
  OpenShift Dev Spaces workspace logs capture IDE extension activity, container memory events, and process errors. Review these logs to diagnose workspace failures, debug misbehaving extensions, and identify memory issues.
- **[View workspace logs in CLI](troubleshoot-proc_viewing_workspace_logs_in_cli.md)**  
  View OpenShift Dev Spaces workspace logs from the OpenShift command-line interface (CLI) to troubleshoot startup failures and runtime errors.
- **[View workspace logs in OpenShift console](troubleshoot-proc_viewing_workspace_logs_in_openshift_console.md)**  
  View OpenShift Dev Spaces workspace logs in the OpenShift web console to diagnose startup failures and runtime errors from the Administrator perspective.

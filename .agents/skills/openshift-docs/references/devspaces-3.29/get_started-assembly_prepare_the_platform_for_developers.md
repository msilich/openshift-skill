# Prepare the platform for developers

Verify that OpenShift Dev Spaces is operational, configure Git provider access for your team, and share the dashboard URL so that developers can create their first cloud development environment.

- **[Your first week as a platform administrator](get_started-con_your_first_week_as_administrator.md)**  
  After installing OpenShift Dev Spaces, complete a short sequence of configuration tasks before inviting developers to the platform. Each task builds on the previous one and takes you from a fresh deployment to a production-ready environment.
- **[Verify the platform works end-to-end](get_started-proc_verify_the_platform_end_to_end.md)**  
  Verify that OpenShift Dev Spaces is operational by checking the Operator status, opening the dashboard, and creating a test workspace. This confirms that the full pipeline works before you invite developers.
- **[Configure GitHub OAuth for your team](get_started-proc_configure_github_oauth_for_your_team.md)**  
  Configure a GitHub OAuth application so that developers can clone repositories and push code from OpenShift Dev Spaces workspaces without manually entering credentials. This procedure covers GitHub.com and GitHub Enterprise Cloud. For other providers, see the Additional resources.
- **[What to configure next](get_started-ref_what_to_configure_next.md)**  
  After verifying the platform and configuring Git access, continue with these configuration tasks based on your organization’s priorities.

# Customize the developer dashboard

Customize the OpenShift Dev Spaces dashboard to control the getting started samples and branding that developers see when they log in.

- **[Customize the dashboard samples for your team](configure-proc_configuring_getting_started_samples.md)**  
  Customize the OpenShift Dev Spaces Dashboard to display custom samples that reflect your organization’s preferred languages, frameworks, and project templates for faster onboarding.
- **[Apply your organization’s branding to the dashboard](configure-proc_customizing_consolelink_icon.md)**  
  Apply custom branding images to the OpenShift Dev Spaces dashboard by overriding the default images in the `assets/branding` directory, so that the dashboard reflects your organization’s visual identity.

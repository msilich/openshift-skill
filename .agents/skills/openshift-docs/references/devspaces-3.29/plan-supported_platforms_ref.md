# Supported platforms and architectures

Confirm that your target cluster runs a supported OpenShift version and CPU architecture before starting the installation.

OpenShift Dev Spaces runs on OpenShift 4.16–4.22 on the following CPU architectures:

- AMD64 and Intel 64 (`x86_64`)
- IBM Z (`s390x`)
- IBM Power (`ppc64le`)
- ARMv8 (`arm64`)

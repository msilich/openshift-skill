# Red Hat OpenShift Dev Spaces release notes

Review what changed in Red Hat OpenShift Dev Spaces 3.29 so that you can plan upgrades and adopt new functionality.

Red Hat OpenShift Dev Spaces creates a Cloud Development Environment (CDE) for your project on Red Hat OpenShift. The dashboard and CLI refer to each CDE as a workspace. A typical deployment includes:

- A CDE server that provisions and manages workspaces
- IDEs such as Microsoft Visual Studio Code - Open Source and JetBrains desktop editors, including IntelliJ IDEA Ultimate, PyCharm, WebStorm, RubyMine, CLion, GoLand, PhpStorm, and Rider
- Containerized environments with common languages, frameworks, and Red Hat technologies

These release notes describe what changed in OpenShift Dev Spaces 3.29 general availability.

This release is based on Eclipse Che 7.118 and 7.119 and includes DevWorkspace Operator 0.42.0.

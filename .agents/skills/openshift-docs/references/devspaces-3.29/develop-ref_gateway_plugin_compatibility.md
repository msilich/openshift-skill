# JetBrains Gateway plugin compatibility matrix

The JetBrains Gateway provider plugin for OpenShift Dev Spaces requires specific versions of the JetBrains Gateway application to function correctly. Only plugin versions 0.0.14 and later are compatible with OpenShift Dev Spaces 3.24 through 3.29.

Plugin versions 0.0.2 through 0.0.13 are not compatible with any supported OpenShift Dev Spaces release.

| OpenShift Dev Spaces version | JetBrains Gateway version | Gateway provider plugin version |
|----|----|----|
| 3.29 | 2025.1.6 – 2026.2 | 0.0.14 – 0.0.18 |
| 3.28 | 2025.1.6 – 2026.2 | 0.0.14 – 0.0.18 |
| 3.27 | 2025.1.6 – 2026.2 | 0.0.14 – 0.0.18 |
| 3.26 | 2025.1.6 – 2026.2 | 0.0.14 – 0.0.18 |
| 3.25 | 2025.1.6 – 2026.2 | 0.0.14 – 0.0.18 |
| 3.24 | 2025.1.6 – 2026.2 | 0.0.14 – 0.0.18 |

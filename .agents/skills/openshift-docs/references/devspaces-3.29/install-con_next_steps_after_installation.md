# Prepare OpenShift Dev Spaces for your team

Prepare OpenShift Dev Spaces for your team by completing these configuration tasks before inviting developers: customize the `CheCluster` resource, connect Git providers for credential-free repository access, and verify end-to-end functionality with a first workspace.

- Verify the platform end-to-end, configure Git provider OAuth, and share the dashboard URL with developers. For a walkthrough of each verification step, see Additional resources.
- Customize the `CheCluster` custom resource to adjust OpenShift Dev Spaces behavior for your environment. For field-by-field configuration guidance, see Additional resources.
- Create your first cloud development environment from a Git repository URL. For a step-by-step workspace creation walkthrough, see Additional resources.

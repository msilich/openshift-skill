# SBOM generation overview

A Software Bill of Materials (SBOM) gives you a detailed overview of the software components, dependencies, and libraries within your application.

RHACS generates an SBOM from the results of the image scans that it performs. You can generate an SBOM by using the RHACS portal, the `roxctl` CLI, or the RHACS API.

<a id="sbom-about_scanner-generate-sbom"></a>

# About SBOMs

A Software Bill of Materials (SBOM) is a digital record that lists the components of a piece of software and their origins. Organizations can use SBOMs to locate the presence of vulnerable software packages and components and respond more quickly to mitigate the risk.

Generating SBOMs also helps organizations comply with "Executive Order 14028: Improving the Nations Cybersecurity".

SBOMs can contain different types of information, depending on the methods of data collection and how you generate them. The Cybersecurity & Infrastructure Security Agency (CISA) offers a document, "Types of Software Bill of Materials (SBOM)", that summarizes the types of SBOMs.

The type of SBOM that RHACS generates is "Analyzed." CISA notes that analyzed SBOMs use an analysis of artifacts such as executables, packages, containers, and virtual machine images. Analyzed SBOMs offer the following benefits, as summarized by CISA:

- They can give information about software without an active development environment.

- You can generate them without access to the build process.

- You can use them to discover hidden dependencies that other tools might miss.

The SBOM generated by RHACS is in "System Package Data Exchange (SPDX) 2.3" format.

# Generate SBOMs

You can generate a Software Bill of Materials (SBOM) by using the Red Hat Advanced Cluster Security for Kubernetes (RHACS) portal, `roxctl` CLI, or API.

<a id="generating-sboms-by-using-the-rhacs-portal_scanner-generate-sbom"></a>

## Generating SBOMs by using the RHACS portal

You can generate a Software Bill of Materials (SBOM) by using the Red Hat Advanced Cluster Security for Kubernetes (RHACS) portal.

<div>

<div class="title">

Procedure

</div>

1.  In the RHACS portal, click the **Vulnerability Management** → **Results** → **\<number\> Images** tab.

2.  Locate the image that you want to use, and do any of the following tasks:

    - Click the overflow menu ![kebab](../../images/kebab.png), and then select **Generate SBOM**.

    - Select the image to view the image details, and then click **Generate SBOM**.

      A window opens that gives information about the image and the SBOM format that RHACS generates. RHACS creates the file in JSON format. Depending on your browser configuration, your browser can automatically download the file to your computer.

</div>

<a id="generating-sboms-by-using-the-roxctl-cli_scanner-generate-sbom"></a>

## Generating SBOMs by using the roxctl CLI

You can generate a Software Bill of Materials (SBOM) by using the `roxctl` CLI.

<div>

<div class="title">

Procedure

</div>

- To generate SBOMs, run the following command:

  ``` terminal
  $ roxctl image sbom --image=<image_name>
  ```

  where:

  `<image_name>`  
  Specifies the name and reference of the image that you want to generate an SBOM for, in string format. For example, `nginx:latest` or `nginx@sha256:…​`.

  For more information, see "roxctl image sbom".

</div>

## Generating SBOMs by using the API

You can use the Red Hat Advanced Cluster Security for Kubernetes (RHACS) API to create a Software Bill of Materials (SBOM).

You must use the `ROX_API_TOKEN` for authorization to connect to the endpoint and generate the SBOM. The API generates the request payload in JSON format.

For more information, see "GenerateSBOM".

# Shared responsibilities for RHACS Cloud Service

In Red Hat Advanced Cluster Security Cloud Service (RHACS Cloud Service), Red Hat manages the services for the main control center, also known as *Central services*. Red Hat is responsible for platform monitoring, updating software for Central services, and other aspects of maintaining hosted components. Customers are responsible for maintaining access to their systems, updating software on secured clusters, and backing up data on secured clusters.
